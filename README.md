# Validador de Lógica de Descuentos

### 📝 Descripción
Script en Python para el cálculo de descuentos comerciales. Incluye validación de reglas de negocio y manejo de excepciones para corregir errores lógicos en el ingreso de precios, cantidades y porcentajes aplicados.

### 🚀 Tecnologías utilizadas
* **Conceptos:** QA Testing inicial, depuración de lógica y validación de rangos numéricos para evitar cálculos negativos o erróneos.
